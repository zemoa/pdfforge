# PDFForge

Portable PDFForge desktop application for Linux x86_64 and Windows x86_64.

The project uses Tauri 2, Vue 3 + TypeScript and Naive UI. It is licensed under AGPL-3.0-or-later, copyright Zemoa.

Read [ARCHITECTURE.md](ARCHITECTURE.md) for the binding design decisions and [DEVELOPMENT.md](DEVELOPMENT.md) to set up, verify and package the application.
