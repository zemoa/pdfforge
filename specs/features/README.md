# Découpage des fonctionnalités — PDFForge

Ce répertoire décompose la [spécification fonctionnelle générale](../SFG.md)
en fonctionnalités implémentables. Il ne complète pas la SFG : les références
indiquées dans chaque fiche restent la source de vérité.

Les fiches ne sont volontairement pas détaillées à ce stade. Leur raffinement
(scénarios, critères d'acceptation et choix de réalisation) devra reprendre
uniquement les décisions explicitement validées dans la SFG ou par
l'utilisateur final.

## Fonctionnalités

1. [FTR-001 — Fusionner des PDF](FTR-001-fusionner-pdf.md)
2. [FTR-002 — Scinder un PDF](FTR-002-scinder-pdf.md)
3. [FTR-003 — Préparer un masquage de texte](FTR-003-masquage-texte.md)
4. [FTR-004 — Préparer un masquage par zone](FTR-004-masquage-zone.md)
5. [FTR-005 — Appliquer un masquage définitif](FTR-005-appliquer-masquage.md)

Les exigences communes à plusieurs opérations (traitement local, conservation
des originaux, destination, confirmation, progression, annulation et gestion
des incidents) sont référencées dans chaque fiche concernée. Elles ne forment
pas une fonctionnalité autonome.
